> **依据**：`计划/M1：地图与 UI 改造.md`、《产品定义与最终开发边界 v1.0》、D0—D3.1 验收记录

> **范围纪律**：仅执行 M1（地图与 UI 改造），不扩展 M2/M3；不改数据库结构与业务 API；不删不改 `/map`、`/map-prototype`、`/terrain`；演示模式继续与真实数据完全隔离；不部署生产。

## 1. 源码现状审查结论（实现前基线）

- `/farm-overview` 主组件 `src/app/(platform)/farm-overview/farm-overview.tsx`（156 行高密度单文件）：天地图**卫星影像 img_w + cia_w 注记**为唯一底图；真实/演示两个独立 `VectorSource`+`VectorLayer`；`INITIAL_CENTER_4326=[114.635,30.25]`、zoom 11；设施在 zoom<13 不渲染；`sessionStorage` 保存/恢复视口与选中；目录、覆盖式右抽屉、演示绘制交互均已具备。
- 底图 URL 由 `src/modules/map-prototype/tianditu.ts` 生成，目前只支持 `img`/`cia` 两类。
- **真实图层样式只有三种**（已核实绿、草稿橙虚线、选中高亮）：农田/塘口/渠道/设施在地图上**没有分类视觉区分**，名称标签也不显示；分类图标（田/塘/闸/泵/测/飞/机）仅用于演示图层。
- 地图工具栏仅有：目录开关、「卫星地图」静态标题、全场视图；无底图切换、无类别显隐、无图例分类说明（图例只有"已核实/草稿"两条）。
- 旧 `/map`（SVG）、`/map-prototype`（私人标点 CRUD）、`/terrain`（Cesium）独立存在，本轮只读不动。
- 样式为 CSS Modules（`farm-overview.module.css`）+ 全局 token（`globals.css` 的 `--forest` 等）；移动端断点 760px/900px。

## 2. 对标研究结论（My Maps / ArcGIS Map Viewer / uMap / 农业运营软件）

| 产品 | 可借鉴的简洁模式 | M1 取舍 |
|---|---|---|
| Google My Maps | 浅色矢量底图为默认、卫星为下拉切换项；左侧图层列表；浏览与"添加"编辑动作分离 | 采用：默认简洁底图 + 底图切换器；编辑入口独立 |
| ArcGIS Map Viewer | BasemapGallery（底图库）与 Legend（图例）是标准微件；Contents 面板管图层显隐 | 采用：工具栏「底图」切换 + 可收起「图层」面板（类别显隐）+ 图例 |
| uMap | 浏览/编辑是两种模式，编辑工具只在编辑模式出现 | 采用：总览页保持浏览模式，绘制/编辑只存在于演示绘制与 `/map-prototype` 独立入口 |
| 农业运营软件（John Deere Operations Center 风格） | 地块绿、水域蓝、设施橙的固定分类色；目录与地图联动定位 | 沿用已有 John Deere 色彩体系，把分类色扩展到真实图层 |

共性结论：**默认低干扰底图、卫星可切换、浏览/编辑分离、图层面板管显隐、图例说明分类语义**。

## 3. M1 设计决策

### D1 默认底图改为天地图矢量，卫星保留切换

- 新增 `vec`（矢量底图）与 `cva`（矢量注记）到 `tianditu.ts` 的 `TiandituLayer`，同一 Key、同一 WMTS 服务、同一 EPSG:3857（`_w`）体系，授权与坐标系无新增风险。
- `/farm-overview` 默认加载 `vec_w + cva_w`（简洁、低干扰、农业业务信息清晰）；工具栏提供「底图：矢量 / 卫星」切换，切换卫星时注记同步换成 `cia_w`。
- 底图选择随会话状态保存（见 D5），页面刷新后保持。
- 任何底图瓦片加载失败沿用现有 `tileloaderror` 可观察诊断。
- `/map-prototype` 保持卫星默认不变（M1 不改其功能）。

### D2 默认视图聚焦梁子湖农业区

- 初始中心仍为梁子湖项目区（农场总览使用自己的 `FARM_HOME_4326` 常量，不改 `map-prototype` 共用的 `INITIAL_CENTER_4326`），初始缩放从 11 调整为 12，避免过大地理范围。
- 真实模式已有"有对象则 fit 授权对象范围"的逻辑保留（maxZoom 14）；演示模式保留全场适应。
- 不绘制、不暗示任何湖泊范围作为农场边界；无坐标对象维持"待登记边界"，不生成假定位。

### D3 地图工具栏与图层面板重规划

```
┌──────────────────────────────────────────────────────────────┐
│ [☰/收起目录] [底图:矢量▾] [图层▾]              [全场视图]      │
│              图层▾ 面板：底图单选(矢量/卫星) · 注记开关        │
│              类别显隐(农田/塘口/设施/机动设备) · 图例          │
└──────────────────────────────────────────────────────────────┘
```

- 工具栏移除静态「卫星地图」标题块，改为动态底图标签；「＋ 新增/管理」在目录展开时仍居目录内，目录收起时出现在工具栏（现状保留）。
- 「图层」面板（地图右上角弹出、可收起、Esc 关闭）：
  - 底图：矢量 / 卫星 单选（与工具栏底图按钮同一状态）；
  - 注记：开/关（默认开）；
  - 业务类别显隐：农田、塘口、渠道、固定设施、机动设备（真实模式按 `kind`；演示模式含 `symbol` 细分）；类别隐藏只影响地图渲染，不改变目录、统计与授权数据；
  - 图例：分类色块 + 边界状态（已核实实线/草稿虚线）+ 演示语义，随模式切换。
- 「编辑地图」低频入口：工具栏不新增真实绘制；保留演示模式的"＋ 新增演示对象"内嵌绘制；真实编辑继续走目录内「新增/管理」与 `/map-prototype` 私人标点（页头已有链接）。即**浏览默认、编辑独立**。

### D4 分类视觉体系（核心）

抽出共享样式模块 `src/app/(platform)/farm-overview/map-symbols.ts`，真实与演示图层统一使用：

| 类别 | 面填充 | 边界线 | 图标 | 备注 |
|---|---|---|---|---|
| 农田 field | 农业绿 `rgba(75,112,45,.24)` | `#4b7045` 实线（草稿虚线） | 绿圆「田」 | |
| 塘口 pond | 水域蓝 `rgba(44,122,164,.22)` | `#2c7aa4` 实线/虚线 | 蓝圆「塘」 | |
| 渠道 channel | — | `#3f8f8a` 实线 | — | 线状要素 |
| 固定设施 facility | — | — | 橙圆「闸/泵/测…」 | zoom<13 渐进隐藏（保留现状） |
| 机动设备 mobile | — | — | 紫圆「飞/机」 | 演示坐标须带"非 GPS"语义 |
| 选中 | — | 白色加粗外描边 | 高亮放大 | 现状语义保留 |

- 所有边界线增加白色衬底描边（底层宽白线 + 上层色线），保证在矢量浅色底图和卫星深色底图上都不与底图混淆。
- 已核实/草稿继续用**实线/虚线**区分（不只靠颜色）；演示图层继续用蓝色系虚线 + "演示（非测绘）"图例语义，与正式边界不混淆。
- 图标从硬编码内联 SVG 迁入 `map-symbols.ts`，同一函数服务真实设施（按 `symbol`/kind 缺省「设施」字标）与演示图层。

### D5 会话状态与可达性

- `farm-overview-return-v1` 状态结构向后兼容地增加 `basemap:'vector'|'satellite'` 与类别显隐；解析时缺省为矢量/全显，旧存档不报错。
- 键盘可达：底图切换、图层面板、类别复选均为原生控件，Esc 关闭面板/抽屉；焦点顺序不破坏现状。
- 移动端（≤760px）：目录抽屉与底部详情保持现状；工具栏按钮压缩为图标 + 短文本；图层面板改为底部弹出卡片。

### D6 工程拆分（低风险）

- 新增 `map-symbols.ts`（分类样式与图标）、`layer-panel.tsx`（底图/注记/类别/图例面板）。
- `farm-overview.tsx` 保持单一主组件，仅替换样式常量与工具栏 JSX；`tianditu.ts` 扩展为 `'img'|'cia'|'vec'|'cva'`。
- 不改 `/api/v1/*`、`src/modules/map/*`、数据库、fixture 坐标与 ID。演示隔离断言（浏览器测试断言 demo 模式零写请求）保持绿色。
