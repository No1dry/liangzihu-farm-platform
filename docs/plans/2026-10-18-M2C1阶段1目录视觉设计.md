# M2-C.1 阶段 1 · 农业资源目录视觉与交互设计说明

> 日期：2026-10-18
> 分支：`m2c1-directory-polish`（基于 `m2c-resource-tree` 顶端 `db9ba8b`）
> 范围：仅阶段 1——视觉设计与真实界面效果图。保留 `@rc-component/tree`、既有定位、归档、恢复、权限与数据语义；不改数据库，不重做全站导航，不进入后续阶段的全面交互改造。

## 1. 目标与当前问题

目标图的核心不是换配色，而是把目录从“数据库字段列表”恢复为资源管理器。当前实现存在：树行自动换行、`对象编号 · 边界状态` 常驻、菜单按钮呈重复小实体按钮、英文眉题与常驻说明占空间、大块深绿新增按钮抢占视觉中心。

## 2. 左侧四个区域

1. **紧凑标题栏**：`农业资源` 标题，右侧轻量 `＋`（原新增/管理入口）和移动端关闭按钮；删除英文眉题与常驻说明。
2. **搜索栏**：单行输入 `搜索村庄、农田、塘口…`。
3. **树目录**：弹性高度、独立滚动；农场→村庄→对象三级，缩进由树组件管理。
4. **底部次要操作**：仅保留轻量 `回收站`；移除重复的 `＋新增` 大按钮。

## 3. 树节点视觉规格

- 行高 40px，flex 单行禁止换行；名称 13px，农场/村庄字重 600，对象 400。
- 每级缩进沿用树组件层级，追加约 16px 的节奏；箭头用 CSS 边框绘制的统一 chevron，不再使用 `▼`/`▶` 字符。
- 结构：`箭头 | 矢量类型图标 | 名称（省略号） | 可选状态微标 | ···`。
- 类型图标统一为内联 SVG：农场/村庄/农田/塘口/设施/机动设备，颜色取现有森林绿/水蓝/暖橙体系；不使用 emoji 或字符三角。
- 状态微标：`草稿`（暖橙虚线语义）、`已核实`（绿色实线语义）、`待登记`（灰色）；完整编号与状态移到 title tooltip 和右侧详情。
- normal：白底、无边框；hover：浅绿底；selected：整行浅绿底 + 2px 左侧标识；`···` 仅在 hover/focus/selected 时显示，触屏常显。
- 长名称：`min-width:0` + 单行省略号，tooltip 显示完整名称；名称不挤压状态与菜单。
- 颜色：主字 `#203A2C`，次要字 `#718175`，选中 `#E8F2EC`，分割线 `#E4EAE3`，危险操作仅归档使用警示色。

## 4. 菜单与移动端（阶段 1 视觉稿范围）

- 桌面菜单锚定当前 `···`，无边框轻量面板，保留既有权限与确认流程；阶段 1 不引入新弹层库。
- 手机目录仍是可关闭抽屉，节点行保持 40px 热区；节点菜单改为底部动作面板（左右 12px、底部 12px），不漂移、不遮挡节点标题；保留 Esc/外点关闭。
- 阶段 3 再处理完整焦点管理、弹层翻转与锚定细节，不在本阶段扩大范围。
