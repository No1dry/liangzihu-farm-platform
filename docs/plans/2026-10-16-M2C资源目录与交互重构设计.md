## 2. 新旧目录结构对比（交付物 2）

| 维度 | 旧（手写 section+ul） | 新（@rc-component/tree） |
|---|---|---|
| 层级 | 村庄只是分组标题，不真正展开/折叠 | 农场→村庄→对象真树形，箭头独立展开/折叠 |
| 定位 | 点对象只高亮，`revealObject` 只在被遮挡时平移 | 点对象/村庄一律 `View.fit()` 原生定位（含抽屉 padding、maxZoom、300ms 动画） |
| 操作入口 | 村庄标题旁常驻「＋」 | 节点 `···` 悬停/聚焦/触摸显示，右键亦可；菜单按节点类型分发 |
| 删除恢复 | 无 | 「移至回收站」（软归档+确认）+ 目录底部回收站入口（查看/恢复） |
| 搜索 | 过滤列表 | 命中保留父级路径并临时展开，清空恢复原展开状态 |
| 持久化 | 查询/选中/视口 | 增加 `expandedKeys` 进 SavedState |

## 3. 数据适配层（`resource-tree.tsx`）

```text
farm:<farmId>（农场，取 objects 中 kind=farm）
├─ region:<regionId>（村庄，map_regions 未归档）
│   └─ <objectId>（农田/塘口/渠道/设施，map_region_links 当前有效关联）
├─ unassigned（未归类对象：无当前关联的非 farm/mobile 对象）
└─（树外）机动设备区块保持现状；目录底部 [＋新增] [回收站] 入口
```

- key 用稳定真实 ID（region: 前缀防与对象 UUID 冲突），不用数组下标；不写回 `objects.parent_id`。
- demo 模式由 demo fixture 构造同款 DataNode，全部只读菜单。
- 数据上限：`listMap LIMIT 500` 现状保留并在页脚明示，不静默扩量；后续如需分页另行设计。
- 展开/选中/搜索三状态独立；`expandedKeys` 入 SavedState（长度上限校验，向后兼容旧存档）。

## 4. 节点交互规范

| 动作 | 结果 |
|---|---|
| 箭头 | 仅展开/折叠（rc-tree switcher，与选中解耦） |
| 村庄名称 | `focusRegion`：关联几何 boundingExtent → `view.fit(extent,{padding:[90,抽屉宽+40,90,60],maxZoom:15,duration:300})`；无可定位对象提示「该村庄暂无可定位的地图资料」 |
| 对象名称 | `selectObject` + `view.fit(对象几何 extent,{padding:[90,抽屉宽+40,90,60],maxZoom:16,duration:300})`；**在视野内也重新定位**；无几何→选中+详情+「尚未登记地图位置」（有配置权时显示「登记边界 ↗」→ /map-editor?object=<id>） |
| 地图点选对象 | 沿用 singleclick → selectedId；树同步 selectedKeys、自动展开父 region、scrollTo 该节点 |
| `···`（悬停/聚焦/触摸/右键） | 打开节点菜单（小弹出层，Esc/外点关闭） |

节点菜单项（无死按钮，按类型/权限过滤）：
- 村庄：地图定位、在该村新增对象（drawer new-object）、修改村庄资料（drawer region-maintenance）、查看关联对象（展开节点）、移至回收站
- 农田/塘口：地图定位、查看详情、修改基本资料（→/objects/{id}）、编辑边界（→/map-editor?object=<id>）、更改所属村庄（drawer change-region）、移至回收站
- 固定设施：地图定位、查看详情、修改基本资料、更改所属村庄、移至回收站（归档服务本轮补齐后可用）
- 演示节点：地图定位、查看详情（只读）

## 5. 归档、回收站与恢复

- **移至回收站**：`confirm()` 通俗说明（如「村庄 X 将从正常目录移除，里面的农田不会被删除，关联历史保留。确定移至回收站？」）→ 农田/塘口/设施 `POST /api/v1/objects/archive {id,version,archived:true,reason}`；村庄 `PATCH /api/v1/map-regions {action:'archive',archived:true,reason}`（服务端自动结束当前关联、校验关联对象权限、写历史）。
- **facility 归档补齐**：`src/modules/registry/objects.ts:56` 允许数组扩展为 `['field','pond','facility']`——全库外键均为 NO ACTION 无级联，归档仅写 archived 字段+版本，安全；补集成测试。不改动 devices/point_bindings 的显示逻辑（验收记录注明设备台账仍可见已归档设施的设备）。
- **回收站**：目录底部入口 → 右抽屉 'recycle-bin' 视图：已归档对象（`/api/v1/objects?action=configure` 过滤 archived_at）与已归档村庄（`/api/v1/map-regions` 过滤）分组列出，显示类型/名称/归档时间；「恢复」按钮（同接口 archived:false，需 configure）→ 恢复后 reload；恢复村庄**不自动恢复历史关联**（界面明示）。
- 「移出村庄」与归档区分：移出 = change-region 选「取消关联」，不动对象本身。

## 6. 定位统一（C2）

- 删除手写 `revealObject` 复杂避让算法，统一为原生 `view.fit()` + 抽屉感知 padding（桌面右侧抽屉约 370px+边距；手机底部抽屉按高度折算），maxZoom 对象 16 / 村庄 15，duration 300。
- 目录点击、地图点击、搜索定位、选中恢复共用同一 `fitToObject(item)` / `fitToRegion(region)`。
