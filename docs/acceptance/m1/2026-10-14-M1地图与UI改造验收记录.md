# M1 地图与 UI 改造验收记录

日期：2026-10-14。依据：`计划/M1：地图与 UI 改造.md`、[M1 设计说明](../../plans/2026-10-14-M1地图与UI改造设计.md)、[产品定义与最终开发边界 v1.0](../../plans/../../../计划/产品定义与最终开发边界%20v1.0.md)。基线 `e3c94d2`（D3.1 完成态），分支 `m1-map-ui-redesign`。所有验证在 luminous 隔离环境（独立 worktree `/data/wfx/liangzihu-m1`、隔离测试库随机 schema）完成；未改动生产部署、生产数据库与 `/map`、`/map-prototype`、`/terrain`。

## 改动摘要

1. **默认底图改为天地图矢量（vec_w + cva_w）**，卫星影像（img_w + cia_w）保留工具栏一键切换；注记随底图联动，可整体关闭；两种底图均挂 `tileloaderror` 诊断。`TiandituLayer` 扩展为 `img/cia/vec/cva`，同一 Key、同一 WMTS/EPSG:3857 体系，无新增授权风险。
2. **默认视图聚焦梁子湖农业区**：农场总览使用自有常量 `FARM_HOME_4326=[114.635,30.25]`、初始 zoom 12（原 11）；有授权对象时仍自动 fit 对象范围。未绘制任何湖泊范围作为农场边界；无坐标对象维持"待登记边界"。
3. **工具栏与图层面板**：目录开关、底图切换、「图层」面板、全场视图。面板含底图单选、注记开关、业务类别显隐（农田/塘口/渠道/固定设施/机动设备，仅影响地图渲染，不改变目录与授权数据）与分类图例；原生控件、Esc 可关。修复了全局 `button:hover` 深色样式遮盖工具栏文字的问题，卫星底图激活态为深绿底白字。
4. **分类视觉体系**：新增 `map-symbols.ts`，真实图层按类别着色（农田绿、塘口蓝、渠道青、设施橙、机动紫），边界加白色衬底描边保证在浅色矢量与深色卫星底图上均可辨识；已核实实线/草稿虚线沿用；设施 zoom<13 渐进隐藏保留；演示图层保持蓝色虚线面 + 分类图标，与正式边界语义不混淆。
5. **会话状态**：`SavedState` 向后兼容增加 `basemap` 与 `visibility`，旧存档缺省为矢量/全显；底图与类别选择变化即写回 sessionStorage，刷新后保持。模式切换（real/demo）保留底图偏好、重置类别显隐。
6. **低频编辑保持独立**：总览页不新增真实绘制；演示内嵌绘制与 `/map-prototype` 私人标点入口保持原样。

| 项目 | 结果 |
|---|---|

| D1 / D2 / D3.1 既有浏览器回归 | 全部通过（断言文案由"天地图卫星影像…"更新为"天地图矢量底图…"，原因：默认底图变更；权限、演示零写请求、状态恢复等断言未削弱） |
| `pnpm test:browser`（platform-browser 平台闭环） | **未通过**："隔离浏览器服务器未启动"。在未改动的基线 main 检出上重跑同样失败，为 luminous 本机预存在问题（该用例不经 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`，且其自建服务探活 10 秒超时）；建议后续单独排查 |

实现过程主控审查修复的两个问题（均在提交前完成）：底图切换因 ref 在渲染期被同步导致瓦片源永不更换；分类样式读取的要素属性名与装载循环不一致（`boundary_status` vs `status`），会导致已核实边界被渲染为草稿虚线。另将底图/类别恢复从 `useState` 惰性初始化改为挂载后恢复，修复 SSR 水合不一致（React #418）。

## 遗留问题

1. 真实多村、真实机动设备定位与现场网络下的底图配额/Key 表现仍需现场验收；本轮为隔离环境工程验证。
2. `platform-browser` 平台闭环用例在 luminous 预存在失败（基线同样失败），与 M1 无关，需单独排查其自建服务探活。
3. 集成测试 8 项备份恢复/模型类失败为 luminous 环境既有问题，建议在该环境补齐模型与备份目标后复测。
4. 图层面板暂不支持点击面板外区域关闭（Esc 与关闭按钮可用）；类别显隐状态在 real/demo 切换时重置为全显。
5. M2/M3（如量测、更多专题图层）未启动，按任务书不在本轮范围。
