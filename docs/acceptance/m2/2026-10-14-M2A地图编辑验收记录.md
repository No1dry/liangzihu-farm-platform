# M2-A 独立地图编辑模式验收记录

日期：2026-10-14。依据：`计划/梁子湖二维 GIS · M2 开发任务.md`、[M2-A 实施设计](../../plans/2026-10-14-M2A独立地图编辑模式设计.md)。分支 `m2-map-editor`（基于 M1 顶端 `71c4123`，M1 尚未合并 main，未从旧 main 开始）。验证在 luminous 隔离环境（worktree `/data/wfx/liangzihu-m1`、隔离测试库随机 schema）完成；未部署生产，未改数据库结构与正式 API 语义。

## 交付内容

- 新路由 `/map-editor`（`src/app/(platform)/map-editor/`）：正式农田/塘口边界的**选择 → 绘制/顶点修改 → 预览 → 保存/取消**完整闭环。
- 对象清单 = `/api/v1/farm-overview` 已授权对象 ∩ `/api/v1/objects?action=configure` 可配置对象 ∩ 农田/塘口；无配置权限账号看到空列表与说明，不显示编辑工具。
- 保存复用 `POST /api/v1/map` 与 `saveBoundary()`：`objects.boundary` 更新+版本递增、`boundary_versions` 历史、`object_versions` 快照全部由原服务完成；坐标经 GeoJSON 3857→4326 转换后以 `sourceCrs=4326` 提交。
- 「已核实」选项只在 `/api/v1/me` 含 review scope 时出现；无 review 强制提交由后端 403 兜底。
- 版本冲突（409）：临时几何与表单保留，提示"他人已更新"，提供「刷新版本后重试」；网络错误、400/422、403 均保留未提交内容并给出语义化提示。
- 继承 M1 视觉体系：默认矢量底图/卫星切换/注记开关/图层面板、分类样式；编辑器内取消、Esc、中文 IME 守卫沿用 map-prototype 范式。
- 入口与返回：`/farm-overview` 页头新增「地图编辑 ↗」（保存会话返回状态）；编辑器页头有「返回农场总览 ↗」「去对象台账新建 ↗」。侧边导航「空间与资料」加入「地图编辑」，worker/expert 导航不可见。

## 审查与调试记录（主控复核发现并已修复）

1. 保存成功后表单卸载导致成功提示不可见 → 状态消息移到地图左下角全局位置持久显示。
2. 浏览器测试塘口绘制点被右下角表单遮挡（`elementFromPoint` 命中 LABEL）→ 绘制区移至地图左中无遮挡区。
3. 顶点拖拽目标超出视口导致几何被拖到视图外 → 目标点改为视图内坐标；第 8 步顶点引用更新为冲突重试后的当前顶点。
4. 「无 review」场景误用 worker（角色本身无 configure 能力）→ 改用 maintainer。
5. `boundary_versions` 计数断言与流程实际版本数对齐；复位视图同时重置缩放至 12。

## 遗留与边界

- `saveBoundary` 无幂等键，重复提交靠前端禁用保存按钮防护；服务端幂等属后续改进。
- 编辑器暂不支持点击地图直接选中对象（左侧列表选择为准）；移动端保证基本可用，精细触控绘制不在本轮。
- 渠道/设施等其他对象类型的边界编辑未纳入 M2-A（服务层已支持 Polygon，后续按需开放）。
- M2-B（测距测面、线段注记、私人面注记）未启动；如需新增私人线面注记数据结构，先提交数据模型与迁移说明。
- luminous 上 `platform-browser` 用例与 8 项集成测试为环境既有失败（基线同样失败），非本轮引入。
